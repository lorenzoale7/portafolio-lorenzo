## Publicar en GitHub Pages
1. Creá un repositorio en GitHub.
2. Subí `index.html` y la carpeta `assets` (podés descomprimir el ZIP y subir todos sus contenidos).
3. En el repositorio, entrá en **Settings → Pages**.
4. En **Build and deployment**, elegí **Deploy from a branch**.
5. Elegí la rama `main` y la carpeta `/ (root)`, guardá los cambios.
6. Esperá a que GitHub Pages publique el sitio y abrí la URL que te muestra.

No necesita instalar dependencias ni compilarse.
